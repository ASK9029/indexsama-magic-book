# IndexSama的魔法录

本地、单用户、离线优先的个人生活管理应用。数据只保存在本机 `data` 目录，不登录、不联网、不上云。

## 功能模块

- **首页**：今日进度、聚合事项（最多 5 条）、快速备忘、学习/健身/饮食/游戏摘要、全局快速添加。
- **今日计划**：手动事项 + 学习安排 + 当天训练 + 计划餐自动汇总；昨日未完成顺延；完成状态来自模块。
- **学习科目**：科目、学习安排、计时器（刷新/重启恢复）、补记、周统计、打卡相册（多图、按科目/日期）。
- **学习资料**：链接、纯文本笔记、本地文件（PDF/图片预览）；搜索/筛选/排序；状态与进度联动。
- **健身计划**：周计划模板、专注训练（组/重量/次数）、历史、升级记录与当前重量、周/月/年统计与体重。
- **饮食计划**：食物库（31 种内置 + 自定义）、计划/实际餐、按计划吃、饮水、体重、周/月/年统计与目标。
- **游戏娱乐**：游戏库、状态日期规则、评分、游玩时长、封面、统计。
- **数据与设置**：主题、每周起始日、体重单位、热量/蛋白/饮水目标、蛋白质参考值、数据概览、完整备份/恢复、清空。

## 开发

```powershell
pnpm install
pnpm dev
```

前端 Vite + React，后端 Fastify + Node 24 `node:sqlite`，仅监听 `127.0.0.1`。

## 测试

```powershell
pnpm test          # 单元/集成（84 个）
pnpm test:package  # 便携打包 + 真实启动（2 个）
pnpm test:e2e      # Playwright 端到端（8 条流程）
pnpm test:all      # 单元/集成 + 打包测试
```

## 打包发布

```powershell
pnpm package
```

产出 `release/IndexSama的魔法录/`：`runtime/node.exe`、`app/server`、`app/client`、`app/node_modules`、`启动IndexSama的魔法录.vbs`、`README.txt`、`data/`。

- 双击 `启动IndexSama的魔法录.vbs` 启动并在浏览器打开；数据始终保存在发布目录的 `data/`，更新程序不会覆盖/删除。
- 端口 43110–43119 自动回退，实际地址写入 `data/server-url.txt`。
- 设置 → 备份：导出完整 zip（数据库 + 文件/照片/封面）；恢复前自动写 `data/backups/pre-restore-*.zip` 留底。
- 设置 → 危险区：必须输入“清空”才会重置数据库、文件与设置。

## 数据

- `data/app.db`：SQLite 主库。
- `data/files/`：资料文件、打卡照片、游戏封面。
- `data/backups/`：恢复前留底。
- 清理浏览器缓存/换浏览器/重启电脑都不会影响 `data`。
