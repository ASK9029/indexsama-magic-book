IndexSama的魔法录 — 本地个人生活管理

启动：
  双击「IndexSama的魔法录.lnk」（带产品图标）；也可以双击「启动IndexSama的魔法录.vbs」。
  首次启动会打开浏览器；之后关闭浏览器不会丢数据。

数据：
  所有数据都在 data 目录（app.db、files、backups）。
  更新程序时只替换 app、runtime、启动脚本，不要删除 data。

退出：
  在「数据与设置 → 数据」里点「退出 APP」，或关闭命令行窗口。

备份：
  设置 → 备份 → 导出备份；恢复前会自动写 pre-restore 留底。

要求：
  Windows 10/11，默认浏览器；无需联网，无需安装 Node。
